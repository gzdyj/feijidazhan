# 第四版踩坑日志

> 记录开发中遇到的异常、BUG、踩坑经验，避免重复踩坑。

---

## 踩坑-000：BOSS 弹"没伤害"是体感问题而非机制缺失
- **现象**：玩家反馈 BOSS 子弹没有伤害
- **排查**：实测机制正常（静止接弹 45 秒后 game over），问题在体感：
  1. 护盾（开局盾/复活盾/护盾道具）把 BOSS 弹全部吸收且无反馈 —— 改为护盾"挡一次即破碎"
  2. 敌弹碰撞半径 `sz+16` 偏小，擦着机身边缘的子弹视觉上命中但未判定 —— 加大到 `sz+22`
  3. 无敌帧期间子弹被"吞掉"无任何表现 —— 改为穿过机身，无敌结束后再判定
- **经验**：反馈"没伤害"时先复现确认机制是否真的失效，再检查护盾/判定/无敌帧等体感因素

## 踩坑-001：触屏模式没有移动逻辑
- **现象**：设置里选择"触屏拖拽"后飞机完全无法移动
- **原因**：update() 中只有 `S.control==='mouse'` 分支跟随指针（touchstart/move 事件虽然写入了 mouseX/Y，但 touch 分支不消费）
- **修复**：跟随条件改为 `S.control!=='keyboard'`，鼠标与触屏统一走指针跟随
- **经验**：多操作模式时，要逐一验证每个模式的实际行为，不能只验证默认模式

## 踩坑-002：高分屏 canvas 模糊
- **现象**：手机（DPR 3）画面整体发虚
- **原因**：canvas 物理像素=CSS 像素，被浏览器放大上采样
- **修复**：resize() 乘 devicePixelRatio（上限 2）+ setTransform
- **经验**：canvas 2D 游戏首查 DPR，这是"模糊"类反馈的第一嫌疑

## 踩坑-003：shadowBlur 在移动端开销巨大
- **现象**：实体越多帧率越低，光效越密集越卡
- **原因**：每个实体一次 shadowBlur 阴影合成，后期实体量暴涨
- **修复**：所有 shadowBlur 赋值收敛到 SB() 开关 + 4档自适应画质降级
- **经验**：shadowBlur 在低端 GPU 上是按像素算的，慎用；要有全局开关

## 踩坑-004：iOS AudioContext 无声
- **现象**：iOS Safari 首次进入无任何音效
- **原因**：AudioContext 需要用户手势解锁，且页面加载时可能处于 suspended
- **修复**：首次 pointerdown/touchstart 时 getCtx().resume()
- **经验**：Web Audio 在移动端必须做手势解锁

## 踩坑-005：弹幕武器音频节点爆炸
- **现象**：弹幕武器射击时出现杂音与卡顿
- **原因**：每秒创建 ~70 个 Oscillator/Gain 节点，GC 压力大
- **修复**：shoot() 50ms 节流
- **经验**：高频音效必须节流或复用节点
