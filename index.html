HOW TO PLAY

玩法与操作

自动射击 · 波次推进 · 每 5 波 BOSS · 多种操作方式随心选

🎮 操作方式

  • 🖱️
    鼠标移动控制战机 · 自动射击
  • ⌨️
    键盘方向键 / WASD 移动 · Shift 加速
  • 💣
    必杀技空格键 释放炸弹清屏（15 秒冷却）
  • 1·2·3
    道具槽数字键释放已拾取的主动技能
  • 📱
    触屏手指拖拽移动战机

🗺️ 战斗流程

  1. 开局自动射击，击落敌机获取分数与金币
  2. 波次每波敌人清空后进入下一波，敌机生成随波次加速
  3. BOSS每 5 波降临强力 BOSS，击破获得大量奖励
  4. 掉落击落敌机概率掉落道具，拾取即时生效
  5. 连击连续击落累积 Combo，分数加成节节攀升

DEPLOY

快速部署

一条命令启动，或直接双击打开 index.html 开玩

🐳 Docker 部署（推荐）

docker run -d -p 8080:80 --name feijidazhan smithgz/feijidazhan:latest

启动后访问 http://localhost:8080 即可游玩。

更多部署方式
docker build -t smithgz/feijidazhan:latest .
docker compose up -d
python -m http.server 8080
npx serve .

🚀 本地运行

游戏是纯静态页面，无需构建工具。直接双击 index.html 即可在浏览器中打开游玩；需要本地服务器时，任选一种方式即可。
